# 사용자 설명서

## 1. 서비스 소개

이 서비스는 학교 노트북의 교내 및 가정 대여 신청, 승인, 반납 기록을 관리하기 위한 웹 애플리케이션입니다. 화면과 이용 가능한 기능은 학생, 담당자, 관리자 등 계정 역할에 따라 달라질 수 있습니다.

## 2. 로그인

1. 서비스 주소에 접속합니다.
2. 로그인 버튼을 선택합니다.
3. 학교에서 허용한 Google 계정으로 인증합니다.
4. 최초 로그인 시 이름, 학번, 학년, 반 등 요청된 프로필 정보를 입력합니다.

공용 컴퓨터에서는 이용 후 반드시 로그아웃하십시오.

## 3. 노트북 대여 신청

### 교과 대여

1. 메뉴에서 교과 대여를 선택합니다.
2. 연도, 월, 주차와 요일별 교시를 선택합니다.
3. 선택한 시간표를 검토하고 통합 신청을 제출합니다.

### 가정 대여

1. 메뉴에서 가정 대여를 선택합니다.
2. 요청 기간과 사유 등 필수 항목을 입력합니다.
3. 학교의 반출 규정을 확인한 뒤 신청합니다.

신청이 접수되었다고 해서 자동으로 승인되는 것은 아닙니다.

## 4. 신청 내역 확인

기록 메뉴에서 본인의 신청 상태를 확인할 수 있습니다. 일반적인 상태는 대기, 승인, 반려, 취소 및 반납 완료입니다. 대기 중인 본인 신청은 취소할 수 있습니다. 승인·반려·반납 결과와 배정된 노트북 번호는 알림 메뉴에도 표시됩니다.

## 5. 담당자 및 관리자 기능

권한을 부여받은 담당자는 담당 반의 신청 목록을 확인하고 승인 또는 반려할 수 있습니다. 승인 시 사용 가능한 노트북이 자동 배정됩니다. 실제 장비를 확인한 뒤 기록 화면에서 반납을 처리하십시오. 관리자 권한은 승인된 업무에만 사용해야 하며 계정을 다른 사람과 공유해서는 안 됩니다.

## 6. 정보 수정과 로그아웃

설정 화면에서 허용된 프로필 정보를 수정할 수 있습니다. 사용을 마친 후 상단 메뉴에서 로그아웃하십시오.

## 7. 문제 해결

- 로그인이 되지 않으면 허용된 학교 계정인지 확인합니다.
- 화면에 데이터가 보이지 않으면 새로고침 후 다시 로그인합니다.
- 권한이 잘못 표시되면 학교 담당자에게 계정과 역할 확인을 요청합니다.
- 개인정보나 보안 문제가 의심되면 화면 캡처를 공개 게시판에 올리지 말고 운영자에게 직접 알립니다.

## 8. 이용자 주의사항

- 다른 사람의 계정을 사용하지 마십시오.
- 학생 개인정보와 대여 기록을 외부에 공유하지 마십시오.
- 승인받은 목적과 기간에 맞게 기기를 사용하십시오.
- 분실, 파손 또는 보안 사고가 발생하면 즉시 학교 담당자에게 알리십시오.
